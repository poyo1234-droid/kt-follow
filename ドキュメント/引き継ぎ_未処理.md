## 注意点（間違えやすいところ）

- **Coworkのファイル連携:** セッション開始時にTドライブのフォルダを接続し忘れない。
  PC上のシェル（device_bash）で読み書き・git可。**Tドライブへの stage／commit（ファイル受け渡し）は失敗する**（fetch or write failed）。
  クラウドで作ったファイルは **ダウンロードフォルダ（C:）へ commit → device_bash で T へ cp** で渡せる（2026-09-11確認）
- **kintoneの読み取り:** ChromeからREST API（GETのみ、`X-Requested-With` ヘッダ付き fetch）。
  データをPCへ渡すときは、ページ内でJSONを作ってダウンロードさせる（Chromeの「自動ダウンロード」は許可済み。保存先が .tmp のままのことがある → 中身は完全）。
  出力にURLのクエリ文字列や `key=value` が含まれるとツール側でブロックされる
- kintone: `https://zrqf50naoiwx.cybozu.com`。商品マスタ＝51、子カテゴリマスタ＝44。
  JSは各アプリのmain.jsのほか、**全体カスタマイズの共通4ファイル**（config.js / KintoneAPIFunctions.js / GoogleAPIFunctions.js / ui.js）を使う。config.js はトークン入りなので伏せて保存済み
